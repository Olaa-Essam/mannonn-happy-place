# Mannonn's Happy Place ♡

A pastel pink + lavender interactive friendship website built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Personalize the website

- Edit the letter in `src/pages/Letter.jsx`.
- Edit the appreciation cards in `src/pages/Reasons.jsx`.
- Add your own photos in the Memories section while the site is open. For photos to remain part of the deployed website, place them in `public/` and update the memory section to reference those files.
- Update the final surprise in `src/pages/Surprise.jsx`.

The mood picker, letter envelope, memory uploader, matching game, and gift reveal are interactive. No backend is required.
